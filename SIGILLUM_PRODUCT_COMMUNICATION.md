# SIGILLUM — Product communication source of truth

Updated: 5 October 2026

## Core promise

**You create. SIGILLUM protects the origin.**

**Create. Certify. Share. Verify.**

SIGILLUM creates a verifiable origin before distribution.

## What the user does

### Photo/video
1. Open SIGILLUM.
2. Capture or record.
3. Save or share.

### Text
1. Write inside SIGILLUM.
2. Tap Certify.
3. Copy, publish or share.

### Verification
- Media: share/select the received file.
- Text: copy the published text and paste it into SIGILLUM.
- Human media comparison: open the protected SIGILLUM reference and compare image/audio when available.

## What SIGILLUM does automatically

### Photo/video
Camera capture inside SIGILLUM → HCV-ID → SHA-256 → Creator/device binding → KYC state when verified → signed certificate → timestamp → optional GPS → capture/display checks → media fingerprints → HCVPACK → secure local original → Registry → protected server reference before external release → automatic or human verification of later copies.

### Text
Text written in SIGILLUM → HCV-ID → hash → text fingerprint → Creator/device binding → signed certificate → Registry → optional text HCVPACK → published-text verification by paste.

## Verification language

Use:
- **SIGILLUM ORIGINAL — IDENTICAL**
- **COPY COMPATIBLE WITH THE SIGILLUM REFERENCE**
- **AUTHORIZED SIGILLUM DERIVATION**
- **MODIFIED COPY**
- **VERIFICATION INCONCLUSIVE**

Scene:
- **Physical-scene evidence**
- **No display evidence**
- **Possible screen recapture**
- **Inconclusive**

Do not present Registry presence alone as proof of media integrity.

## Commercial differentiator

SIGILLUM does not simply receive an arbitrary file later and label it as an original. For photo/video certification, the origin is created through the SIGILLUM Camera. Once a protected original reference has been registered before external release, later digital changes can be checked against that prior reference.

**To bypass the digital chain without breaking it, deception must move in front of the camera.** This can include a display, projection, print or a physically staged scene. SIGILLUM therefore also records technical scene/display signals.

## Compatibility

**iPhone only. iOS 16.0 or later. Technically iPhone 8, iPhone 8 Plus and iPhone X or later.**

Full validation of advanced capture/ML behaviour on the oldest technically installable devices remains a release requirement.
