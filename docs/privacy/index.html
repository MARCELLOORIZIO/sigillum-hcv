Privacy Policy

Last updated: 3 July 2026

SIGILLUM is designed to minimize server-side storage of original media. The service focuses on technical certificates, identifiers and verification data.

English

Data processed

  • Content created or selected by the user, such as photos, videos, text, documents or HCVPACK files.
  • HCV-ID, cryptographic file hash, technical fingerprint, certificate data and verification status.
  • Technical metadata required to create or verify a certificate, such as file type, timestamps and app-generated verification data.
  • Technical creator identity data when configured, such as device key fingerprint and user-declared creator name.
  • Future identity verification status if KYC is enabled through an external provider.

How data is used

  • To create, sign and verify HCV certificates.
  • To recover certificates through the online Registry.
  • To distinguish original, compatible derived, non-verified and risk-marked content.
  • To provide support, diagnose errors and respond to user requests.

Original media

In the intended production model, original photos, videos and text are stored on the user's device and may be saved in the user's Photos library. The online Registry stores certificate and verification data such as HCV-ID, hashes, fingerprints, metadata and identity status. Original media is not sold and is not used for behavioral advertising.

Registry data

Registry records may need to remain available to preserve the ability to verify certified content. If a deletion request is received, SIGILLUM will evaluate which personal data can be deleted and which technical certificate records must be retained to preserve integrity and auditability.

KYC and identity

If identity verification is introduced, SIGILLUM should use a specialized provider. Identity documents and selfies should be processed by that provider where possible. SIGILLUM should store only the verification status, provider reference and minimum technical data needed to link an identity status to a creator account.

Contact

For privacy, support or deletion requests, use the instructions on the Support and Delete data pages.
