Help for certification, verification and social sharing.

How to verify content from social apps

  1. Open the photo or video in Photos, Facebook, Messenger, WhatsApp or another app.
  2. Tap Share.
  3. Choose SIGILLUM from the list of apps.
  4. If iOS shows a SIGILLUM sharing screen, close it or tap Open SIGILLUM.
  5. Open SIGILLUM manually if needed. The verification should start automatically for the shared file.

Common results

  • Verified: the content is linked to a valid certificate and available checks are consistent.
  • Compatible derivative: the file appears to be a recompressed or modified version that remains technically compatible with the certificate.
  • Not verified: the file cannot be matched to a valid SIGILLUM certificate.
  • Screen risk: SIGILLUM detected caution signals related to possible screen replay.
  • Not analyzed: a specific analysis could not be completed and should not be treated as a successful result.
